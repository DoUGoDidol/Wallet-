# 零花钱管家 v2 — CAD / iPhone PWA

## 预算模型
- 总资金池：C$1,830。分类额度 C$550 + C$480 + C$500 + C$300 = C$1,830，是同一资金的分配，不是额外的钱。
- 实际余额 = 初始预算 + 额外收入 − 所有消费。支出如果导致负余额，会被阻止。
- 日常消费计入周预算 C$35、分类额度和全年余额；大件消费不计入日常周预算，但仍扣全年余额和对应分类额度。
- 周按周一至周日，月按自然月。周额度结转是可用预算参考，不会增加总余额；年度总余额和分类额度依然是硬限制。
- 大件目标只追踪进度，不会自动扣账；实际购买需要单独记一笔，避免重复扣款。
- 额外收入可记账；当前版本暂未实现分类之间转账。

## 免费部署与 iPhone 安装
1. 解压 ZIP，将 index.html、manifest.json、sw.js、icon-192.png、icon-512.png 上传到 GitHub 仓库根目录。
2. GitHub 仓库 Settings → Pages，选择 main 分支和根目录发布。
3. 在 iPhone Safari 打开发布后的 HTTPS 地址。
4. 点分享 → 添加到主屏幕 → 添加。
5. 首次联网打开后，Service Worker 缓存应用文件。账目保存在本机浏览器 localStorage，不会自动 iCloud 同步。定期导出 JSON 备份。

此版本无实时商品比价、系统级通知或云同步。清除 Safari 网站数据可能丢失账目。导入备份会覆盖当前数据。更改全年总预算不会自动重分配分类额度，请保持四类额度合计不超过总预算。
